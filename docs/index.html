Dust ReproductionDust 复现

Dust (Dahal et al., 2026) trains a transformer language model without a backward pass. It adds noise to activations at every token and turns the loss changes that follow into a gradient estimate. The paper reports that this matches backpropagation (backprop) at pretraining. We ran the official release, added the AdamW baseline it lacks, and tested Dust on models that backprop had already trained.Dust（Dahal 等，2026）不做反向传播就能训练 transformer 语言模型：它在每个 token 的激活上加噪声，再把随之产生的 loss 变化转成梯度估计。论文称它在预训练上与反向传播（backpropagation，下称 backprop）相当。我们跑了官方 release，补上了它缺少的 AdamW baseline，并在 backprop 已经训练过的模型上测试了 Dust。

What was run跑了什么

For a linear layer with output \(y_t\) at token \(t\), Dust adds noise \(\sigma a_t\) with \(a_t \sim \mathcal{N}(0, I)\), reruns the forward pass, and rewards each token's noise with the loss reduction \(r_t\) it caused. Averaged over \(K\) independent draws,对一个在 token \(t\) 处输出 \(y_t\) 的线性层，Dust 加上噪声 \(\sigma a_t\)（\(a_t \sim \mathcal{N}(0, I)\)），重跑前向，并用该噪声带来的 loss 下降量 \(r_t\) 给它打分。对 \(K\) 次独立抽样（draw）取平均，

\(\hat g_t = -\dfrac{1}{K\sigma}\displaystyle\sum_{i=1}^{K} r_t^{(i)}\, a_t^{(i)}\)

estimates the error at the layer's output, and its outer product with the layer's cached input is the weight gradient. \(K\) is the population. Attention queries, keys and values are scored against the estimated error of the attention output instead of the loss. The derivation is below for readers who want it.就得到该层输出处的误差估计，它与该层缓存输入的外积即权重梯度。\(K\) 称为 population。注意力的 query、key 和 value 不直接用 loss 打分，而是用注意力输出的误差估计打分。想看推导的读者可以展开下面一节。

Derivation: why noise times loss change estimates the gradient推导：为什么“噪声 × loss 变化”能估出梯度

What is estimated. For \(y_t = W x_t\), backprop gives \(\partial L / \partial W = \sum_t \delta_t x_t^\top\) with \(\delta_t = \partial L / \partial y_t\). The input \(x_t\) is known from the forward pass, so only \(\delta_t\) needs the backward pass. Dust estimates \(\delta_t\) without it.要估计的量。对 \(y_t = W x_t\)，backprop 给出 \(\partial L / \partial W = \sum_t \delta_t x_t^\top\)，其中 \(\delta_t = \partial L / \partial y_t\)。输入 \(x_t\) 在前向时已知，只有 \(\delta_t\) 需要反向传播。Dust 不做反向传播来估计 \(\delta_t\)。

The estimator. The noise goes on the layer's output, not on its weights: \(y_s \to y_s + \sigma a_s\) at every token \(s\), with \(W\) unchanged. A first-order Taylor expansion of the loss in these outputs gives the perturbed loss \(L + \sigma \sum_s \delta_s^\top a_s\), where \(\delta_s = \partial L / \partial y_s\) is the quantity defined above at token \(s\); the index \(s\) runs over all tokens and \(t\) is the one being estimated. The reward is therefore \(r \approx -\sigma \sum_s \delta_s^\top a_s\). Multiplying by one token's noise and averaging,估计器。噪声加在该层的输出上，而不是权重上：每个 token \(s\) 处 \(y_s \to y_s + \sigma a_s\)，\(W\) 不变。把 loss 对这些输出做一阶泰勒展开，扰动后的 loss 是 \(L + \sigma \sum_s \delta_s^\top a_s\)，其中 \(\delta_s = \partial L / \partial y_s\) 就是上面定义的量在 token \(s\) 处的取值；下标 \(s\) 遍历所有 token，\(t\) 是当前要估计的那个。于是打分 \(r \approx -\sigma \sum_s \delta_s^\top a_s\)。把它乘上某个 token 的噪声再取期望，

\(-\dfrac{1}{\sigma}\,\mathbb{E}\big[r\,a_t\big] = \mathbb{E}\big[a_t a_t^\top\big]\,\delta_t + \displaystyle\sum_{s \neq t} \mathbb{E}\big[a_t a_s^\top\big]\,\delta_s = \delta_t ,\)

because \(\mathbb{E}[a_t a_t^\top] = I\) and the noise at different tokens is independent with zero mean. Replacing the expectation by an average over \(K\) draws gives \(\hat g_t\).因为 \(\mathbb{E}[a_t a_t^\top] = I\)，且不同 token 的噪声相互独立、均值为零。把期望换成 \(K\) 次 draw 的平均，就得到 \(\hat g_t\)。

Rewards per token. The total loss also moves because of the noise at every other token, and that part of the reward has nothing to do with \(a_t\). Over many draws it averages to zero, so it does not bias the estimate. In any single draw it is a large random number multiplying \(a_t\): for a sequence of \(T\) tokens its variance is on the order of \(T\) times that of the signal, so about \(T\) times as many draws would be needed. Dust therefore rewards a token with the loss reduction \(c_s\) at individual positions, not with the change of the total loss. Let \(\ell_s\) be the next-token cross-entropy at position \(s\) and \(\ell_s^{(i)}\) its value under draw \(i\). For the \(n\) draws evaluated together in one batched forward pass, \(c_s^{(i)} = \tfrac{1}{n}\sum_{j=1}^{n} \ell_s^{(j)} - \ell_s^{(i)}\): how much lower the loss at \(s\) is under this draw than under the average draw. The reward of the noise at token \(t\) is then逐 token 打分。总 loss 的变化里还包含其他所有 token 的噪声造成的部分，这部分打分和 \(a_t\) 毫无关系。对很多次 draw 取平均时它趋于零，所以不会让估计有偏；但在单次 draw 里，它是一个很大的随机数乘在 \(a_t\) 上：序列长为 \(T\) 时，它的方差大约是信号的 \(T\) 倍，也就是需要约 \(T\) 倍的 draw 才能平均掉。所以 Dust 不用总 loss 的变化，而是用各个位置上的 loss 下降量 \(c_s\) 来打分。记 \(\ell_s\) 为位置 \(s\) 处预测下一个 token 的交叉熵，\(\ell_s^{(i)}\) 为第 \(i\) 次 draw 下的取值。对同一次批量前向里一起评估的 \(n\) 次 draw，\(c_s^{(i)} = \tfrac{1}{n}\sum_{j=1}^{n} \ell_s^{(j)} - \ell_s^{(i)}\)，即这次 draw 下位置 \(s\) 的 loss 比平均 draw 低多少。token \(t\) 处噪声的打分则是

\(r_t = \displaystyle\sum_{s \ge t} \gamma^{\,s-t}\, c_s .\)

Under causal attention a perturbation at \(t\) cannot change the loss at earlier tokens, so dropping them only removes variance. The decay \(\gamma\) trades bias for variance. With \(\gamma = 1\) the estimate is unbiased for backprop's \(\delta_t\) to first order. With \(\gamma = 0\) it keeps only the token's own loss and estimates \(\partial \ell_t / \partial y_t\), leaving out the later tokens that read this activation through attention. The paper uses \(\gamma = 0\) for layers scored by the loss and about 0.98 for keys and values. The baseline in \(c_s\) is the mean over draws and not the unperturbed loss because noise shifts the loss by a second-order amount that is about the same in every draw, typically upward, and that common offset would multiply \(a_t\) as pure noise. A baseline that does not depend on \(a_t\) leaves the expectation unchanged, since \(\mathbb{E}[a_t] = 0\). This mean includes the draw itself, which shrinks the estimate by the known factor \((n-1)/n\) without changing its direction. The release uses \(n\) = 2 to 16 depending on the population.在因果注意力下，\(t\) 处的扰动改变不了更早 token 的 loss，所以丢掉它们只会减小方差。衰减 \(\gamma\) 在偏差和方差之间折中。\(\gamma = 1\) 时，估计在一阶近似下是 backprop 的 \(\delta_t\) 的无偏估计。\(\gamma = 0\) 时只保留本 token 的 loss，估计的是 \(\partial \ell_t / \partial y_t\)，漏掉了后面通过注意力读取这个激活的 token。论文对用 loss 打分的层取 \(\gamma = 0\)，对 key 和 value 取约 0.98。\(c_s\) 用同批 draw 的均值而不是未扰动的 loss 作基线，是因为噪声会让 loss 整体偏移一个二阶小量（通常是升高），每次 draw 都差不多；这个公共偏移乘在 \(a_t\) 上就是纯噪声。只要基线与 \(a_t\) 无关，由于 \(\mathbb{E}[a_t] = 0\)，期望不变。这里的均值包含了本次 draw 自己，所以估计会按已知系数 \((n-1)/n\) 缩小，方向不变。release 里 \(n\) 随 population 取 2 到 16。

Why the population must be large. One draw, \(a\,(a^\top \delta)\), has the right mean, but \(a\) has \(d\) dimensions and only the one along \(\delta\) carries signal. After \(K\) draws the cosine with the true gradient is roughly \(1 / \sqrt{1 + c/K}\) with \(c\) of the order of \(d\), plus interference from the other perturbed tokens and layers. The paper fits \(c_{\max} / \sqrt{1 + c/K}\) to its measured cosines.为什么 population 必须很大。单次 draw 的估计 \(a\,(a^\top \delta)\) 均值正确，但 \(a\) 有 \(d\) 个维度，只有沿 \(\delta\) 的那一个带信号。\(K\) 次 draw 之后，它与真实梯度的余弦大致是 \(1 / \sqrt{1 + c/K}\)，其中 \(c\) 与 \(d\) 同量级，再加上其他被扰动的 token 和层带来的干扰。论文用 \(c_{\max} / \sqrt{1 + c/K}\) 拟合它测到的余弦。

Virtual population. Adding \(\sigma a_t\) to the output at token \(t\) is the same as using the weights \(W + \sigma a_t x_t^\top / \lVert x_t \rVert^2\) at that token alone, a rank-one weight perturbation. Each token has its own \(a_t\), so one forward pass evaluates as many weight perturbations as there are tokens in the batch, where weight-space evolution strategies evaluate one.虚拟 population。在 token \(t\) 的输出上加 \(\sigma a_t\)，等价于只在这个 token 上使用权重 \(W + \sigma a_t x_t^\top / \lVert x_t \rVert^2\)，即一个秩一的权重扰动。每个 token 有自己的 \(a_t\)，所以一次前向评估的权重扰动数等于 batch 里的 token 数，而权重空间的进化策略一次只评估一个。

Attention internals. Noise on queries, keys and values moves the loss too little to read. Dust first estimates the error \(\hat g^{\,o}_s\) at the attention output as above, then recomputes only that block's attention under the noise and scores the change \(\Delta o_s\) of its output with \(c_s = -\langle \hat g^{\,o}_s, \Delta o_s \rangle\), a linear stand-in for the loss reduction.注意力内部。query、key、value 上的噪声对 loss 的影响太小，读不出来。Dust 先按上面的办法估出注意力输出处的误差 \(\hat g^{\,o}_s\)，再只重算这一层在噪声下的注意力，用 \(c_s = -\langle \hat g^{\,o}_s, \Delta o_s \rangle\) 给输出的变化 \(\Delta o_s\) 打分，作为 loss 下降量的线性替代。

Our reading, not the paper's: with \(\gamma = 0\) the estimate leaves out the effect of an activation on later tokens, so it targets a truncated gradient rather than backprop's. That may be one reason the fitted ceilings \(c_{\max}\) stay below one for most layers. And since the estimate gets noisier relative to the signal as training proceeds, it fits what we see below: the gap to backprop widens with steps, and a trained checkpoint needs a smaller learning rate.以下是我们的解读，不是论文的说法：\(\gamma = 0\) 时，估计漏掉了一个激活对后续 token 的影响，所以它逼近的是截断后的梯度，而不是 backprop 的梯度。这可能是多数层拟合出的上限 \(c_{\max}\) 低于 1 的原因之一。另外，随着训练推进，估计的噪声相对信号越来越大，这与下文看到的现象相符：与 backprop 的差距随步数扩大，训练过的 checkpoint 需要更小的学习率。

Against AdamW与 AdamW 对比

Within one optimizer the paper's claim holds. With SGD, Dust is level with backprop from a population of about a thousand at 1M tokens and close behind it at 10M. But SGD at a constant learning rate is a weak way to train this model. Backprop with AdamW is far better at both budgets, and its lead over SGD grows with tokens (Table 2). The paper's own Adam experiment stops at 1M tokens, where a whole run is 61 steps.在同一种优化器内，论文的结论成立。用 SGD 时，Dust 在 1M token 上从 population 约一千起就与 backprop 持平，在 10M 上紧随其后。但恒定学习率的 SGD 并不是训练这个模型的好办法。backprop 换成 AdamW 后在两个预算上都好得多，而且它对 SGD 的领先随 token 数增大（表 2）。论文自己的 Adam 实验只做到 1M token，整个训练只有 61 步。

At 10M tokens Dust under Adam is the better Dust variant from a population of 1k, and it beats backprop with SGD. Against backprop with AdamW the answer depends on when one looks (Figure 2). For the first hundred steps the largest population is nearly on top of backprop. From a population of 1k the gap then widens until the end of training; at 256 Dust starts slowly, so the gap narrows before it widens again (Table 3). A larger population delays the divergence and does not remove it, which agrees with the paper's own remark that the population needed to match backprop grows with tokens.在 10M token 上，从 population 1k 起 Adam 版 Dust 都优于 SGD 版，并且超过了 backprop SGD。和 backprop AdamW 相比，结论取决于看训练的哪个阶段（图 2）。前一百步里，最大 population 的 Dust 几乎贴着 backprop；此后 population 1k 及以上的差距持续扩大，直到训练结束；population 256 的 Dust 起步慢，差距先缩小再扩大（表 3）。更大的 population 只是推迟了分叉，并没有消除它，这与论文自己的说法一致：要追平 backprop 所需的 population 随 token 数增长。

Can tuning close the gap?调参能补上差距吗？

Not along the two axes we tried (the matrix learning rate and \(\beta_1\)). Dust's Adam settings come from the paper's 61-step runs, so at a population of 1k we varied the two that most plausibly depend on run length, the learning rate and \(\beta_1\). Halving the learning rate helps slightly and every other change is worse (Table 4). Backprop's learning rate is bracketed at both budgets, with the paper's value best.在我们试过的两个方向（矩阵学习率和 \(\beta_1\)）上不能。Dust 的 Adam 设置来自论文 61 步的运行，所以我们在 population 1k 上改了最可能随训练长度变化的两项：学习率和 \(\beta_1\)。学习率减半略有帮助，其余改动都更差（表 4）。backprop 的学习率在两个预算上都已被夹住，论文的取值最好。

Seeds do not change the picture. We repeated one Dust cell with three seeds; they agree to within 0.01, far less than the distance to backprop with AdamW (Table 5).换 seed 也不改变结论。我们把一个 Dust 格子用三个 seed 重复，它们之间相差不超过 0.01，远小于与 backprop AdamW 的差距（表 5）。

We did not vary how draws are split across layers, the noise scales or the credit decay. The paper tuned these for SGD in its largest 10M-token cell and reports that only a slower decay and a shift of draws toward attention paid off there.我们没有改变 draw 在各层之间的分配、噪声尺度和 credit decay。论文在 10M token 的最大一格上为 SGD 调过这些，称只有更慢的 decay 和把 draw 向注意力一侧倾斜有收益。

Continuing a backprop checkpoint从 backprop checkpoint 续训

The paper argues that backprop explores the loss landscape poorly. If so, a zeroth-order method should be able to improve a model that backprop has trained, a test proposed by You Jiacheng. We trained two checkpoints with backprop and AdamW, on 10M and on 100M tokens, and continued each for 200 steps on tokens that neither the checkpoint nor the held-out sets contain. All runs but one start from a fresh optimizer state, so backprop and Dust are treated alike; the remaining run keeps backprop's AdamW state as the uninterrupted reference.论文认为 backprop 对 loss 地形的探索不足。若是如此，零阶方法应该能改进 backprop 训练过的模型，这是 You Jiacheng 提出的检验。我们用 backprop AdamW 训了两个 checkpoint，分别用 10M 和 100M token，然后各续训 200 步，所用 token 既不在 checkpoint 的训练数据里，也不在留出集里。除一组外，所有运行都从全新的优化器状态开始，以便 backprop 与 Dust 受到同等对待；剩下那组保留 backprop 的 AdamW 状态，作为不中断训练的参照。

  • At the learning rates tuned for training from scratch, Dust improves neither checkpoint. The loss ends at or above where it started at every population.用从头训练时调出的学习率，Dust 对两个 checkpoint 都没有改进：每个 population 下，最终 loss 都不低于起点。
  • At a learning rate of 0.0005 Dust lowers the loss steadily from both checkpoints, and a larger population lowers it further. It stays above backprop at the same learning rate throughout (Figure 3).把学习率降到 0.0005 后，Dust 在两个 checkpoint 上都能稳定降低 loss，population 越大降得越多；但它始终高于同学习率的 backprop（图 3）。
  • Backprop also gains from the lower learning rate, and at the 100M-token checkpoint the original rate makes no progress at all. That checkpoint therefore mostly tests whether a noisier gradient estimate still works with a small step, and less whether Dust explores better.backprop 同样受益于更低的学习率；在 100M token 的 checkpoint 上，原学习率已经完全不再下降。所以这个 checkpoint 主要检验的是：噪声更大的梯度估计配上小步长还能不能用，而不是 Dust 是否探索得更好。

The proposal asked for a checkpoint below a loss of 3 with the GPT-2 tokenizer. Ours start at 3.98 and 3.25 with a 4,096-token vocabulary. Losses are not comparable across tokenizers, and these are certainly weaker models than the one proposed.原提议要求的是 GPT-2 tokenizer 下 loss 低于 3 的 checkpoint。我们的起点是 4,096 词表下的 3.98 和 3.25。不同 tokenizer 的 loss 不能直接比较，而这两个模型肯定比提议中的弱。

Cost代价

Dust pays for each unit of population with a forward pass. With this release the largest population takes eight GPUs for hours where backprop takes one GPU for seconds or minutes (Table 7). Two things bias the ratios. The times include evaluation, which is most of backprop's wall clock, so the ratios understate the difference in training compute. And the minimal release reruns the whole network for every draw, which the paper's own implementation avoids.Dust 的每一单位 population 都要付出一次前向。用这份 release，最大 population 需要 8 张 GPU 跑数小时，而 backprop 只需 1 张 GPU 跑数秒到数分钟（表 7）。有两点会让比值偏移：计时包含评估，而评估占了 backprop 墙钟时间的大部分，所以比值低估了训练算力的差距；另外最小实现每次 draw 都重跑整个网络，论文自己的实现避免了这一点。

Claims we did not rerun我们没有重跑的论点

Three of the paper's claims are outside what the release lets us run. For two of them the paper's own numbers already say something, and we set those out here. Nothing in this section is our measurement.论文有三个论点超出了 release 能跑的范围。其中两个，论文自己的数字已经能说明一些问题，这里把它们列出来。本节没有任何一项是我们的测量。

Larger models. The paper reports that at a fixed population larger models reach a lower loss. Backprop shows the same pattern in the same table, so the comparison that isolates Dust is its distance to backprop at each size. That distance grows with model size at every population from 1k up (Table 8). The study uses SGD, and its largest model is worse than the next smaller one for both methods, which suggests 10M tokens is too little data for it.更大的模型。论文称在固定 population 下更大的模型 loss 更低。同一张表里 backprop 也是这个规律，所以能单独说明 Dust 的，是各尺寸下它与 backprop 的差距。从 population 1k 起，这个差距在每个 population 下都随模型变大而增大（表 8）。这个实验用的是 SGD，而且两种方法下最大的模型都不如次大的，说明 10M token 对它来说数据太少。

Gradient alignment. The paper measures the cosine between Dust's estimate and the backprop gradient at populations up to 131,072 and fits \(c_{\max} / \sqrt{1 + c/K}\) per layer type. Its largest training population is 16,384. Putting that value into the published fits gives a cosine near one half for the feed-forward layers and near one fifth for keys and values (Table 9). The paper's point that the cosine does not fall between 10M and 1B tokens may well hold; our runs show that this alone does not keep the loss level with backprop under Adam.梯度对齐。论文在最大 131,072 的 population 下测量 Dust 的估计与 backprop 梯度的余弦，并按层类型拟合 \(c_{\max} / \sqrt{1 + c/K}\)。而它训练时用的最大 population 是 16,384。把这个值代入论文公布的拟合，前馈层的余弦约为二分之一，key 和 value 约为五分之一（表 9）。论文说余弦在 10M 到 1B token 之间不下降，这很可能成立；但我们的运行表明，在 Adam 下仅凭这一点并不能让 loss 跟上 backprop。

EGGROLL. The weight-space baseline is not in the release, so the claim of a thousand to ten thousand times better efficiency is unchecked. In the paper, the measured part is that EGGROLL at 256 times the population still trails Dust; the larger factor extrapolates a curve that is still falling.EGGROLL。这个权重空间的 baseline 不在 release 里，所以"效率高一千到一万倍"的说法没有核对。论文中实测的部分是：EGGROLL 用 256 倍的 population 仍落后于 Dust；更大的倍数是对一条仍在下降的曲线做的外推。

Limits of this reproduction本次复现的局限

  • One seed per Dust run, except the cell in Table 5. Backprop's three seeds differ by about 0.06 at 1M tokens and 0.08 at 10M, so differences of that size between Dust cells are not resolved.除 表 5 中的那一格外，每个 Dust 运行只有一个 seed。backprop 的三个 seed 在 1M token 上相差约 0.06，在 10M 上约 0.08，所以 Dust 各格之间这个量级的差别无法分辨。
  • Dust under Adam is a reconstruction. The split of draws across blocks is our assumption; it matches the four published points at 1M tokens and has no published reference at 10M.Adam 版 Dust 是重建的。draw 在各层之间的分配是我们的假设；它在 1M token 上与论文公布的四个点一致，在 10M 上没有可对照的公布数值。
  • At 10M tokens Dust's Adam settings were varied along two axes (the matrix learning rate and \(\beta_1\)) at one population only (1k).10M token 上 Dust 的 Adam 设置只在一个 population（1k）上沿两个方向（矩阵学习率和 \(\beta_1\)）调过。
  • The largest population here is 16,384. The paper's Adam ladder at 1M tokens goes to 65,536, and its claim of ending below backprop rests on an extrapolation beyond that.这里的最大 population 是 16,384。论文在 1M token 的 Adam 实验做到 65,536，而它"最终低于 backprop"的说法依赖更远的外推。
  • Continuation runs last 200 steps from two checkpoints, with one learning rate below the default for Dust.续训只有 200 步、两个 checkpoint，Dust 只试了一个低于默认值的学习率。
